# riscv-pipelined-fpga

Day-by-day build log for a pipelined RISC-V CPU targeting FPGA.

## Goal

Build a simple, readable, and testable pipelined RISC-V processor design that can eventually run on FPGA hardware.

## Day 1

- Initialize the Git repository.
- Create the project README.
- Set up the remote GitHub repository.

## Planned Milestones

- Define the supported RISC-V subset.
- Build the single-cycle baseline.
- Add instruction and data memory models.
- Split the datapath into pipeline stages.
- Add hazard detection and forwarding.
- Simulate with focused test programs.
- Prepare FPGA synthesis and bring-up notes.
